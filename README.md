# 하늘그네 봇 조직도

봇이 어떻게 나뉘고, 무엇을 주고받고, 어떤 순서로 판단하는지 보여주는 한 장짜리 정적 페이지입니다.

브라우저로 `index.html`을 열면 됩니다. 빌드는 없습니다. GitHub Pages는 저장소 루트를 그대로 사이트로 쓰면 됩니다.

## 화면

- **조직** — 노드를 누르면 역할, 도구, 규칙이 나옵니다. 위에 올리면 연결된 선이 굵어집니다. 색 선은 방입니다.
- **흐름** — 공모전 작업, 사실 검증, 그림. 재생하면 패킷이 단계마다 이동합니다.
- **판단** — 일을 받은 뒤부터 드라이브에 남기기까지. 단계를 눌러 이동할 수 있습니다.
- **규칙** — 승인, 봇끼리 문장, 커넥터 범위, 미발표 원고, 비밀.

메일 주소, 계정, 비밀번호, 키는 적혀 있지 않습니다.

글꼴은 Noto Sans KR, Black Han Sans의 부분 집합이며 OFL입니다. 라이선스는 `fonts/`에 있습니다.
